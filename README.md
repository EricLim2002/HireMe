Project Setup

This project is built using Laravel + Vite as the build tool and includes modern frontend libraries for styling and animations.

🔧 Tech Stack

Laravel Vite Plugin – integrates Laravel with Vite for fast builds and hot module reloading.

Vite – modern frontend build tool for fast development and optimized production builds.

Tailwind CSS – utility-first CSS framework for responsive UI design.

Bootstrap 5 – CSS framework for layout and components.

Axios – HTTP client for making API requests.

GSAP (GreenSock Animation Platform) – for advanced animations and smooth transitions.

tsparticles – particle animations (engine, slim, preset-links).

📦 Dependencies Overview
Dependencies

@tsparticles/engine, @tsparticles/slim, tsparticles-preset-links → used for animated particles.

bootstrap → responsive design & UI components.

gsap → animations.

Dev Dependencies

vite → build tool.

laravel-vite-plugin → Laravel integration with Vite.

tailwindcss & @tailwindcss/vite → Tailwind setup.

axios → API requests.

concurrently → run multiple commands in parallel (e.g., frontend + backend).

🚀 Scripts

npm run dev → start development server.

npm run build → build for production.

⚙️ How to Run

Clone the repository

git clone <repo-url>
cd <project-folder>


Install dependencies

npm install


Start development server

npm run dev


Build for production

npm run build
